# 100 Days of Web Development

This repository documents my journey through the **100 Days of Web Development** course by Maximilian Schwarzmüller.

As I progress through the course, I will upload exercises, projects, and notes to track my learning and development as a web developer.

Throughout the course, I will learn:

+ How the web works and the fundamentals of web development
+ HTML, CSS, and JavaScript for building modern user 
+ interfaces
+ Node.js and Express for backend development
+ SQL and NoSQL databases
+ Authentication, file uploads, and other advanced web 
+ development concepts
+ How to build complete websites, web applications, and 
+ web services

This repository serves as both a learning journal and a collection of projects created during the course.
